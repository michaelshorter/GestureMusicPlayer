Put your songs in this folder, named after the gesture labels:

  disco.mp3
  football.mp3
  rock.mp3
  rave.mp3

The Processing sketch loads one file per label in triggerLabels, and will
stop on startup if a file is missing. If you remove a label from
triggerLabels, you don't need its mp3.

The mp3 files are not included in this repository (see .gitignore),
because the tracks are copyrighted. Use your own music.
